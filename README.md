## 🔬 Research Interests

My current research focuses on developing **real-time human activity recognition systems on edge devices**. I work across the complete pipeline, from sensor data acquisition and embedded programming to machine learning model development and edge inference.

I'm particularly interested in building efficient, low-latency intelligent systems that process data closer to where it is generated.
